# Fabiola y César

14 de noviembre de 2026. Verde, beige y dorado. Sin fotografías, código de vestimenta ni mesa de regalos; únicamente pases personalizados y confirmación dentro del pase.

Misa: Parroquia de San Andrés Jilotepec, 14:00. Recepción: Rancho Santa Rita, 16:00. Itinerario solicitado: misa 14:00, ceremonia civil 15:45, comida 16:30.

Audio existente: `/audio/fabiolaycesar.mp3`.

Las ilustraciones SVG de iglesia, rancho y ramas se crearon para esta invitación. Sobre generado con IA con sello F&C y arreglo floral de IA de Caleb y Ciriam. Misma paleta verde olivo, beige champaña y dorado, incluido el papel del sobre. Frase y Mateo 19:6 con mayúsculas y minúsculas normales, sin cursivas.

Para vincular una cuenta, usar `node scripts/provision-event.js fabiola-y-cesar CORREO` cuando se proporcione el correo. No se ha inventado contacto de WhatsApp.

Evento activado en Firebase con autorización explícita del usuario el 22 de octubre de 2026: registro publicado y confirmaciones habilitadas. Pases disponibles desde el panel de administración. No se creó una cuenta de cliente. El despliegue del código en Vercel sigue pendiente. Las pruebas de confirmación se hicieron con datos y API simulados.
